# DevFlow Frontend

Modern frontend for DevFlow, an enterprise-grade issue tracking and project management platform.


## Architecture

Frontend

React
↓
Axios
↓
Express API
↓
MySQL

Realtime

React
↓
Socket.IO Client
↓
Socket.IO Server


## Features

- JWT Authentication
- Dashboard Analytics
- Project Management
- Issue Tracking
- Issue Assignment
- Notifications
- Activity Timeline
- Comments System
- User Profiles
- Search & Filters
- Real-Time Updates
- Responsive UI

## Tech Stack

- React
- Vite
- Axios
- React Router
- Tailwind CSS
- Recharts
- Socket.IO Client

## Color Palette

## Typography

- Body: Spectral
